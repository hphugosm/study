# Baroko

Předmět: Dějepis. Stabilní ID tématu: `baroque`.

Nejdřív čti `sources/index.json`: obsahuje jen schválené původní podklady. Seznam je zatím prázdný; obsah chybějících podkladů neodhaduj.

Nové výtahy, poznámky a procvičování patří do `derived/`, samostatně od zdrojů, s odkazy na přesná ID a SHA-256 použitých podkladů. Již existující výpisky nejsou automaticky považované za původní zdroje. Nic se tu automaticky negeneruje. Pravidla jsou v [návodu pro další práci](../../../../../../../docs/moodle-source-catalog.md).
