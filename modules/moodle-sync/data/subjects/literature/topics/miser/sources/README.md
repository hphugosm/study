# Původní podklady

Sem patří pouze schválené zdrojové soubory pojmenované SHA-256 a uvedené v `index.json`. Neměň jejich bajty při tvorbě výtahů. Neukládej sem výtahy, přihlašovací údaje ani soukromé exporty Moodlu.

Nové přílohy jsou v GitHub Releases; jejich schválené kanonické URL jsou v `index.json`. Starší již veřejné lokální originály mohou nadále používat `path`.
