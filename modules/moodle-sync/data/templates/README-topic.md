# Veřejně schválený název tématu

Předmět: veřejně schválený název. Stabilní identita: `subject-name / topic-name`.

## Původní podklady

Čti `sources/index.json`. Použij jen jeho schválené soubory a ověř skutečné SHA-256. Pokud je seznam prázdný, chybějící zadání nebo obsah neodhaduj.

## Další výstupy

Výtahy, poznámky, kartičky a procvičování mají vlastní složku `derived/<artifact-id>/` a záznam v `derived/index.json`, který odkazuje na přesná ID a SHA-256 původních zdrojů. Neschválené koncepty zůstávají mimo veřejný repozitář. Tato šablona sama neopravňuje ke zveřejnění materiálů ani ke spouštění modelových API.
